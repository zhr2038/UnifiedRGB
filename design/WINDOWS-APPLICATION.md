# Windows 应用交付

目标：在 Windows 10/11 x64 上通过标准安装包安装光域，首次配置不依赖开发目录或作者机器的硬件地址。安装包自带 .NET 运行环境；当前驱动、硬件型号与原生协议的支持范围仍须核对。

## 首次配置界面

- 视觉方向：深色中性底、清晰的中文层级、单一青色操作强调；与光域主界面一致。
- 内容顺序：欢迎与运行方式 → 当前电脑的设备与依赖 → 明确选择接管范围 → 保存并启动。
- 交互方向：检测过程呈现实际状态；步骤切换轻微淡入；主要按钮的悬停和忙碌状态明确可见。

硬件不存在时可以进入虚拟演示。不能把作者的风扇地址、USB 实例、屏幕绑定、校准、场景、厂商停用记录复制给其他人。设备发现成功与物理播放确认须分开显示。安装和设备发现不能触发灯光标记、LCD 重置、PWM、风扇/水泵设置或厂商卸载。

## 安装与更新

程序文件安装到 Program Files，数据保留在 ProgramData/UnifiedRgb，界面日志在 LocalAppData/UnifiedRgb。后台通过现有受审查的计划任务以管理员身份运行；界面保持普通用户权限。更新必须保留本机配置、场景包、绑定、安装方向和校准，退出失败时不能覆盖运行文件。卸载默认保留用户数据，不自动删除驱动或停用厂商应用。

独立压缩组件必须有可分发的来源、固定版本和第三方许可说明。公开包不包含从厂商安装目录复制且未确认可分发的 yuz.dll。

### 开发安装脚本的生命周期约束

`tools/install.ps1` / `tools/uninstall.ps1` 通过 `tools/installation/UnifiedRgb.Installation.psm1` 工作。安装根目录必须是 Program Files 下的明确子目录。程序文件按版本放在 `versions/<id>`，所有权清单记录每个文件的路径、长度和 SHA-256。先暂存和核验完整版本，确认 GUI 关闭、原后台退出后才切换既有计划任务；失败时保留可回退版本。升级从已安装版本携带完整 appsettings.json 字节，不用源默认值覆盖本机未知字段。

卸载先确认后台退出，再执行既有服务恢复操作；只删除清单中未被修改的自有文件。未知文件、修改过的配置、用户数据和驱动均保留；旧的 `-Purge` 参数明确拒绝。没有所有权清单的旧版平铺目录不会被猜测为可删除目录，需要独立迁移。

离线验证入口是 `tools/windows/installation-qa/Invoke-InstallationQa.ps1`，只使用临时文件和模拟进程、任务、注册表、维护命令与时钟。该工具已接入 Windows CI；本机模拟测试通过不等于已完成真实管理员安装、干净系统升级、签名或完整 Setup 验收。

## 发布门槛

干净源码构建、回归测试、实际自包含程序启动、安装/升级/卸载隔离验证、发布文件完整性检查完成后，才发布正式下载。不使用本机正在运行的程序做破坏性安装测试；未完成的实机或干净系统测试如实记录。
