# 黑金原生工作台

采用已确认的 Figma 黑金方案：纯黑画布、石墨面板、暖白正文、香槟金选中态。保留原有 WPF、可信命名管道和 Host 独占设备的结构。

工作台分为“内置灯效”和“外部导入”。原有路径编排、设备校准、屏幕管理、场景库、诊断和偏好设置均保留。显卡示意为三风扇，两组竖向装饰灯位于相邻风扇空档。示意布局不修改已校准的物理映射。

外部包支持灯光亮度、色相、整体速度、整组反向、灯光启用，以及屏幕画面亮度、适配、叠层、强调色、发送上限、启用和长屏监控区域。速度和反向共用原包时间轴；色相与灯光亮度不改变屏幕素材。设备时钟精度、包时长和现有严格传输预算仍在应用前检查。

原始 ZIP 不变。参数和绑定保存为独立的不可变版本；原始参数继续使用原有 schema1，调整版本使用 schema2 和显式 editor-v1 播放契约。保存不应用；另存场景固定内容与版本；应用比较预期版本，拒绝过时窗口的操作。

动态示意图按哈希校验后的原始 RGB24 帧本地绘制。五屏预演按需缓存原素材并以相同源时间拖动或播放；支持分段 MP4、GIF 与静态图。预演限制 25 次刷新每秒，缓存有容量上限。监控信息使用真实采样，过期值显示待更新。机箱和监控布局为示意；屏幕页另保留实际编码预览。预演不是设备光学回读，不保证实机可见帧率或相位。

软件验收覆盖原始参数兼容、独立版本、实际命名管道接口、过时版本拒绝、保存与应用分离，以及原生 WPF 的动态帧、时间轴和监控采样。当前机器的运行模块另完成 579 项配对测试。此前隔离目录与契约不匹配的失败记录保留；不能将这些结果称为一次全绿调用。部署前需验证既有公开 API 未被候选契约删除。

源码中的视频诊断、预备叠层和队列测量只用于显式受控试验，默认关闭；CFR 选帧及访问单元批处理辅助类尚未接入常规播放。它们不构成稳定可见 60 FPS 或实机光学同步的验收。

部署仅替换 App 和必要的 Host/Contracts 文件；不替换既有灯光、屏幕传输及编码模块。完整备份运行目录和 ProgramData，比较最新场景、屏幕内容、本机设置及全部受保护文件。若五屏未恢复运行或保护数据不同，回滚程序文件并保留失败证据。
