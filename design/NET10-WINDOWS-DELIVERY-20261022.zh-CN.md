# .NET 10、来源与 Windows 安装交付

本轮保留 WPF、MVVM、AsyncCommand、Host、RPC 与设备传输边界。场景包契约、屏幕编码策略、设备安装方向和本机持久化格式不因运行时升级而改写。当前场景与私有素材不进入分发包。

## 运行时

- SDK 基线 10.0.402，运行库 10.0.13，继续使用 C# 12。自包含、非单文件、无裁剪，保留 WPF 资源和原生接口的动态加载路径。
- Microsoft.Extensions / ServiceController 10.0.13；StreamJsonRpc 2.26.150、MessagePack 2.5.307；Serilog 4.3.0 及匹配的 Hosting / Configuration。
- .NET 10 的传递依赖审计发现旧 MessagePack 2.5.187 的已知漏洞；通过升级依赖解决，没有禁用审计或降低警告级别。
- BackgroundService 的启动行为、命名管道就绪、关闭、旧客户端接口、屏幕合成和时钟继续回归。编码协议和原生命令不随此次迁移重写。

微软 [.NET 支持政策](https://dotnet.microsoft.com/en-us/platform/support/policy/dotnet-core)列出 .NET 10 LTS 支持至 2028-11-14；版本来自官方 [10.0 发布元数据](https://builds.dotnet.microsoft.com/dotnet/release-metadata/10.0/releases.json)。构建工具包下载后核对官方 SHA512，保留旧 SDK 以便回退。

## 内容来源

历史 LConnect 动画体和三个厂商采样表从当前产品移除。保留兼容路由、帧布局、时钟单位和实测几何；像素改用原有可再生的 34 个数学灯效及独立区间堆积公式。原有整扇堆积、冷头高度映射和三秒波浪回退保持几何回归。其他内置路径模式的视觉曲线经过重新设计，不能承诺复刻厂商画面。

旧配置中的 `Vendor` / `LConnect` 标识继续读取，界面显示“路径循环”；不往场景包增加字段。已保存的帧动画仍使用原始素材和帧字节。重设计者接触过历史研究，**不声称 clean room**，也没有重写公开 Git 历史。细节见 [来源清单](../SOURCE-PROVENANCE.md)。

原通用生成器的数学金样保留；失效的厂商采样表和逐字节参考测试改为新内容的确定性、方向、几何、预算和资源排除检查。初始失败日志保留，不把旧参考失效解释为“首轮全部通过”。Core 从1014变为1004：移除七个不再涉及产品的旧表算术案例，颜色轮询改为均匀效果后少三个平移分类案例。新增两项维护锁测试及102项首次配置测试。

## 安装器

入口为 `tools/packaging/Build-Windows.ps1`，生成单个 Windows x64 Setup EXE。NSIS 3.11 使用固定 SHA256、标准 MUI2 / nsExec 和 zlib，不带额外运行时下载器。安装器需要由人确认 Windows UAC，不绕过系统确认。

- 自包含 Host、App、CLI、Setup；不要求用户安装 .NET 或 Python。
- Program Files 下按版本暂存、逐文件 SHA256 校验、切换任务，保留上一版本和完整 appsettings 字节。
- App、Host 和 Setup 参加维护启动锁；界面或配置向导未退出时拒绝安装，保护草稿。旧版本仍保留进程检查与回退保护。
- 开始菜单提供程序、设备配置和卸载入口；Host 使用既有管理员计划任务，App 保持普通权限。
- 配置向导默认演示，不复制作者设备地址。发现、协议/依赖验证、输出授权与物理验收分开；不因用户勾选便批量设置 ControlVerified。
- 未知配置字段、既有设备安装信息和未在线设备记录保留。首次配置写入采用并发哈希、原子替换与备份；不修改场景、屏幕方向、原包或素材。
- 卸载保留用户数据、未知文件和被修改的配置，不卸载驱动或擅自停用厂商程序。

自包含合并只对 Microsoft.VisualBasic / System.Drawing 两个框架转发程序集选择经过包哈希验证的 WindowsDesktop 超集版本，记录选择前后 SHA。其他同名文件不同则拒绝，不静默覆盖应用依赖。

许可载荷包含依赖元数据、原始许可及通知、tinyuz MIT、屏幕协议归属和 NSIS 通知。PawnIO 模块不修改，附带 LGPL、对应源文件、同一 commit 的全部必要头文件与 SHA；系统驱动和 PawnIOLib.dll 仍是独立前提，厂商 DLL 不分发。项目没有因此被整体改成某个依赖的许可证。
