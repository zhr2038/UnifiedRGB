# Effect generation

`python tools/codegen/gen_effects.py --check` verifies all 34 generic effect C# implementations without writing anything. No dependencies or private inputs are required. Run without `--check` to regenerate after deliberately editing a body in this script; use `--output PATH` for a separate comparison directory.

The generator existed in the local development tree but was excluded from the public repository by the tools allowlist. The audit remediation includes it, rather than inventing a replacement generator. All 34 generated files matched the current implementations before this change, with line endings normalized. Verification does not start the program or access hardware.

This generator covers only `Core/Effects/Generators/*Effect.cs`. The compatibility bodies and embedded vendor-derived tables under `Core/Effects/LianLi` have separate provenance and are not generated by it. Their historical extraction tools require private reverse-engineering inputs, which are not distributed. Including this generic generator does not establish redistribution rights for vendor components or make a clean-room claim.
